# Preemie Delivery

## Supplies

| Thermal hat               | Preemie diaper |
|---------------------------|----------------|
| Preemie sized face masks (3) | Limb leads    |
| 00 blade                  | 4x4 gauze      |
| Plastic wrap              |                |

## Checklist

to be read by the team leader prior to delivery, after OB sign-out and once the bed is prepared.

1. Members state their own names and roles

2. Plan
   ➔ Diagnoses: Pre-eclampsia, PPROM etc.  
   ➔ EFW, GA, Betamethasone? Magnesium infusion?  
   ➔ Delayed cord clamping (60 seconds) if demonstrating respiratory effort  
   ➔ HOB dries face and leader puts on hat  
   ➔ Mask PPV with emphasis on mask and reposition with jaw thrust  
   ➔ Transition to bCPAP after stabilization if <32wks and not intubated  
   ➔ Weight in del room  

3. Equipment check
   ➔ Appropriate size mask, Pedi cap in-line  
   ➔ Thermal hat, mattress cracked, plastic wrap  
   ➔ bCPAP, measuring tape  
   ➔ ETT and blade prepped if <30wk  

4. Communication check
   ➔ Use closed loop communication  
   ➔ If you see something, say something  
   ➔ Any concerns?

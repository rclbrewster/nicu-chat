# NICU LISA & SALSA

**Audience:** Respiratory Care Practices (RCPs), Nurses (RNs), Advanced Practice Providers (APPs)

## Objective:
Present indications & procedures for Less Invasive Surfactant Administration (LISA) and Surfactant Administration using Laryngeal Supraglottic Airway (SALSA).

## Usage:
The selection of surfactant administration methods are based on the patient’s gestation age, respiratory status and oxygen requirement.

| Infants ≤ 24+6 weeks GA or <750 grams BW | Infants 25 to 27+6 weeks GA or 750 to1250 grams BW No apnea or Congenital facial anomalies | Infants ≥ 28 weeks GA and > 1250 grams BW |
|------------------------------------------|------------------------------------------------------------------------------------------|------------------------------------------|
| Decision to give Surf                    |                                                                                          |                                          |
| ![Red arrow down]                        | ![Blue arrow down]                                                                       | ![Green arrow down]                      |
| Intubate using RSI                       | Attempt LISA                                                                             | SALSA                                    |
|                                          | ETT with RSI if unsuccessful                                                             |                                          |

*GA: gestational age; BW: birth weight; EGA: estimated gestational age; RSI: rapid sequence induction*

# LISA

## OBJECTIVE:

Less invasive surfactant administration, uses 16g angiocath, inserted via video laryngoscope into the trachea to administer surfactant while maintaining patient on BCPAP. It will be a clinical decision to provide surfactant without plans to initiate invasive mechanical ventilation. Must be spontaneously breathing without apnea.

## EQUIPMENT:

- 16G angiocath
- Video laryngoscope
- Enteral feeding tube
- Pink tape (mark at weight + 5.5)
- Measuring tape
- Marking pen
- Syringe with surfactant
- Connector tubing to angiocath

*[Image: Video laryngoscope, Enteral feeding tube, 16G Angiocath]*

## EQUIPMENT SETUP:

- Check all PPV equipment, including Pedicap in line.
- Ensure properly sized and functioning BCPAP
- Gather intubation supplies at bedside
- Have ventilator available if NIPPV/intubation is needed
- Obtain surfactant from pharmacy
- Add 0.5-1ml of air to surfactant syringe
- Ensure insertion depth is marked on angiocath with pink tape by MD/APP, eg. 5.5 + wt(kg)
- Ensure OG tube is in place with syringe attached to empty stomach contents
- Ensure infant swaddled to immobilize arms/legs but with chest uncovered

## PRE-PROCEDURE:

| LISA Pre-Procedure                                      | MD | RN | RCP |
|---------------------------------------------------------|----|----|-----|
| Time- Out is performed.                                 | X  |    |     |
| Pre-medication is administered.                         | X  |    |     |
| Position and pre-oxygenate patient w/ goal SpO2 > 94%.  |    |    | X   |
| Suction patient’s mouth.                                |    |    | X   |
| Stomach is emptied via OG tube.                         |    |    | X   |

# PROCEDURE:

| LISA Procedure                                                                 | MD | RN | RCP |
|-------------------------------------------------------------------------------|----|----|-----|
| While maintaining patient on BCPAP throughout the procedure, obtain view of cords via video laryngoscope. | X  |    |     |
| Suction and cricoid provided as needed.                                       |    | X  |     |
| RCP hands provider marked angiocath.                                          |    |    | X   |
| Angiocath is inserted by provider.                                            | X  |    |     |
| Videoscope is removed and angiocath held in place by provider.                | X  |    |     |
| RCP connects surfactant syringe to angiocath to administer surfactant via connector tubing. |    |    | X   |
| Surfactant is administered in at least 3 aliquots over a minimum of 1 minute, slowing or pausing for any reflux into the stomach or irregular breathing or decompensation. |    |    | X   |
| Between each aliquot, bedside RN pulls back on OG to see if patient is refluxing any surfactant. |    | X  |     |
| Reminder of team at bedside is monitoring vital signs and stimulating patient throughout process. | X  | X  | X   |
| After final aliquot of surfactant is delivered, RCP will administer final aliquot of air to clear catheter and ensure all surfactant has been delivered. |    |    | X   |
| Angiocath is then removed.                                                    | X  |    |     |
| Entire team stay at bedside for 10 minutes post procedure.                    | X  | X  | X   |
| Wean FiO2 rapidly post procedure.                                             | X  | X  |     |
| If more than two unsuccessful attempts, convert to intubation.                | X  | X  | X   |

# SALSA

## OBJECTIVE:
Surfactant administration using laryngeal supraglottic airway, aims to provide surfactant via LMA using a MAC catheter, while PPV is provided to patient w/ NeoTee. Patient will simultaneously be supported on BCPAP.

## EQUIPMENT:
- LMA
- 5ml syringe for LMA cuff inflation
- Y-adaptor
- Multi-access catheter
- CO2 detector
- NeoTee
- Syringe with surfactant

## EQUIPMENT SET UP:
- Check all PPV equipment
- Pedicap in line
- Ensure properly sized and functioning BCPAP
- Gather intubation and SALSA supplies at bedside
- Check cuff on LMA
- Have ventilator available if NIPPV/intubation is needed
- Obtain surfactant from pharmacy
- Add 0.5-1ml of air to surfactant syringe
- Attach surfactant syringe and prime multi-access catheter

## PRE-PROCEDURE:

| SALSA Pre-Procedure                              | MD | RN | RCP |
|--------------------------------------------------|----|----|-----|
| Time out is performed by MD/APP                  | X  |    |     |
| Sweet-ease vs Lorazepam vs Precedex is administered by RN followed by atropine |    | X  |     |
| Position infant in sniffing position             |    |    | X   |
| RN will aspirate stomach contents, remove OG, suction mouth, leaving CPAP on |    | X  |     |

# PROCEDURE:

| SALSA Procedure                                                                 | MD | RN | RCP |
|---------------------------------------------------------------------------------|----|----|-----|
| While maintaining patient on BCPAP throughout the procedure, provider opens mouth, grasps tongue with left thumb, and inserts LMA. | X  |    |     |
| If cuffed, inflate LMA (<3ml).                                                  | X  |    |     |
| After LMA in place, attach Y-adaptor with NeoTee and CO2 detector.              | X  |    |     |
| Provide support necessary to maintain SpO2 > 94%. Increase FiO2 PRN.            | X  |    |     |
| If no color change, provider will advance further.                              | X  |    |     |
| If bradycardia, provider will retract slightly.                                 | X  |    |     |
| If significant event, remove LMA, provide PPV, and re-attempt x1.               | X  | X  |     |
| Proceed to instill surfactant if vital signs are appropriate by attaching primed multi-access catheter to Y-adaptor. | X  |    |     |
| Advance multi-access catheter to appropriate depth and withdraw between each aliquot. |    |    | X   |
| Surfactant is administered in at least 3 aliquots over 1 minutes                | X  |    |     |
| After each aliquot, provide support (bag if needed) to achieve stable vital signs | X  |    |     |
| Once surfactant has been administered, if cuffed, deflate, and remove LMA.      | X  |    |     |
| RN will replace OG and aspirate stomach to see if surfactant was delivered into stomach |    | X  |     |
